## 表关系概览

```
customer (1) ──→ (N) magnet_config, magnet_config_qa, order, shipping_address, content_play, magnet_play_content_configs, play_content_confirm_jobs
customer ──→ industry_solution (industry_solution_id)
magnet_config (1) ──→ (N) magnet_config_cta, order, order_item, user, magnet_play_content_configs, play_news_contents, rel_magnetconfig_contentcategory
magnet_config_cta ──→ solution_method (solution_method_id)
order (1) ──→ (N) order_item, payment
shipping_address (1) ──→ (N) order
magnet_pricing_plan (1) ──→ (N) order
magnet (1) ──→ (N) play_content_log, user_action_log, no_answer_qa, yes_answer_qa, usage_request_log
magnet_config_qa (1) ──→ (N) play_content_log
magnet_config_qa ──→ industry_solution (industry_solution_Id)
user (1) ──→ (N) user_chat_log, user_action_log, play_content_log
play_news_sources (1) ──→ (N) play_raw_news, task_logs
play_raw_news (1) ──→ (N) play_news_scores, play_news_contents
industry_solution (1) ──→ (N) customer, magnet_config_qa, industry_solution_config
solution_module (1) ──→ (N) solution_function, industry_solution_config
solution_function (1) ──→ (N) solution_method, industry_solution_config
solution_method (1) ──→ (N) magnet_config_cta, industry_solution_config
magnet_play_content_configs (1) ──→ (N) play_news_contents, play_content_units
play_content_category (category_code) ←── rel_magnetconfig_contentcategory (play_content_category_code)
play_content_category ←── play_news_contents (content_category_code，与 category_code 对应；外键以实际库为准)
industry_solution (1) ──→ (N) industry_solution_config
industry_solution ──→ industry (industry_id)
industry (1) ──→ (N) base_qa, industry_solution, play_news_contents

play_news_contents ──→ industry (industry_id)
base_qa、magnet_pricing_tier、play_zip_code、prompt_config、play_contents、industry_website_config、industry_webapp_config、legal_document（当前无外键依赖或独立配置）
```

## 数据流转与模块说明

### 客户与订单

- **customer**：客户主表，可关联 Supabase Auth（auth_user_id）、行业解决方案（industry_solution_id）；被订单、冰箱贴配置、收货地址、内容播放引用。
- **order / order_item / payment**：订单、明细、支付；订单可关联 shipping_address、magnet_pricing_plan、magnet_config。
- **shipping_address**：收货地址，支持 Google 地址验证与默认地址。

### 冰箱贴与 QA

- **magnet_config**：冰箱贴配置（团队名、正反面图等），归属客户。
- **magnet_config_cta**：每个配置下的 CTA 联系人及分配数量（allocated_count），可关联 solution_method、支持 skip_url 跳转。
- **magnet**：具体冰箱贴实例，关联 magnet_config_cta、magnet_config，被播放日志、行为日志、无/有答案 QA、usage 引用。
- **base_qa**：标准知识库（含 vector 向量）；**magnet_config_qa**：客户可用问题库，归属客户，可关联 industry_solution。

### 用户行为与日志

- **user**：基于 session 的访问用户，关联 magnet_config。
- **user_action_log**：触碰/播放/对话/call_me 等行为。
- **play_content_log**：播放记录（user、magnet、magnet_config_qa、play_news_contents）。
- **user_chat_log**：对话记录（user、magnet、question/answer）。
- **no_answer_qa / yes_answer_qa**：无答案/有答案问题，均关联 magnet.id。
- **usage_request_log**：Token 与费用统计，关联 magnet.id。

### 新闻与内容流（play_*）

- **play_news_sources** → **play_raw_news** → **play_news_scores**、**play_news_contents**：信号源 → 原始新闻 → 评分与冰箱贴内容。
- **play_content_category**：播放类目字典（category_code 唯一）；**rel_magnetconfig_contentcategory**：magnet_config 与类目多对多（同一配置多行为类目**并集**）；与 **play_news_contents.content_category_code** 对应。
- **播放器取数（后端）**：`magnet.magnet_config_id` → **rel_magnetconfig_contentcategory** → `content_category_code IN (...)` 查 **play_news_contents**；无类目或主查无结果时用 **三字段为空**的保底行（config_id、magnet_config_id、content_category_code 均为 NULL/空串，且不按 zip 过滤）。**rss / long_text** 仍仅按 **magnet_play_content_configs** + **play_news_contents.config_id**，不走类目与保底。
- **play_zip_code**：美国邮编字典。
- **task_logs**：抓取等任务日志，关联 play_news_sources。

### 行业解决方案（官网 / Studio / WebApp）

- **industry**：行业数据表（code、name），行业字典；被 base_qa（indestry_id）、industry_solution（industry_id）、play_news_contents（industry_id）引用。
- **industry_solution**：行业解决方案主表，每行业仅一条 is_active=true，生成 Studio 访问路由；关联 industry（industry_id）、industry_name 存储行业名称。
- **industry_website_config**：行业官网内容配置，按路由与文图（官网渲染用）；已移除 industry_id。
- **industry_solution_config**：方案包含的模块/功能/方法，约束 Studio 可配置项；依赖 **solution_module**、**solution_function**、**solution_method** 字典。
- **industry_webapp_config**：WebApp 功能开关或默认行为（如 player_autoplay、cta_style）；已移除 industry_id。
- **customer**：新增 industry_solution_id，关联行业解决方案。
- **magnet_config_cta**：新增 solution_method_id、skip_url，支持 CTA 方法配置与跳转。

### 播放内容配置与任务

- **magnet_play_content_configs**：客户/冰箱贴下的播放内容来源配置（source_type: file/rss，processing_type: once/periodic）；被 play_news_contents、play_content_units 引用；与 **按类目取 latest** 路径并行存在（由 `magnet_play_content_configs` 是否存在及 source/processing 类型分支决定）。
- **play_content_units**：每个配置下的单条内容单元（raw_text、processed_data、order_index）。
- **play_content_confirm_jobs**：客户上传内容后的解析/编排/转音频任务（status: parsing → curating → converting_to_audio → done/error，RLS 已启用）。

### 其他

- **content_play**：客户级内容播放配置（RSS、TTS、CTA、展示信息）。
- **play_contents**：UUID 主键的播放内容表（customer_id 为 uuid）。
- **magnet_pricing_plan / magnet_pricing_tier**：定价计划与阶梯单价（RLS 已启用）。
- **prompt_config**：全局播放文本/主图/标题提取的 prompt 配置。
- **legal_document**：法律/静态文档（Terms、Privacy、Addenda），RLS 已启用。

## 注意事项

1. 时间字段统一使用 `timestamp with time zone`（除部分 start_time/end_time 为 timestamp without time zone）。
2. **user_chat_log**、**play_content_log** 等表中存在拼写 **megnet**（应为 magnet），表中字段名以实际数据库为准；**magnet_config_qa** 中 **industry_solution_Id** 为大写 I，以实际数据库为准。
3. **order** 表同时存在 **pricing_plan_id** 与 **magnet_pricing_plan** 外键；**order_item.magnet_id** 指向 **magnet_config.id**。
4. **customer** 与 **auth.users** 通过 **auth_user_id** 关联，用于登录客户体系；**customer** 新增 **industry_solution_id** 关联行业解决方案。
5. **magnet_pricing_plan**、**magnet_pricing_tier**、**play_content_confirm_jobs**、**legal_document** 启用了 RLS，其余表 RLS 未启用。
6. **industry** 表为行业数据字典（id、code、name、created_at）；**base_qa.indestry_id**、**industry_solution.industry_id**、**play_news_contents.industry_id** 关联 industry；**base_qa** 中 indestry_id 为拼写（应为 industry_id）。
7. **play_news_contents.industry_solution_id** 若仍存在，**播放器相关接口**已不再按该字段筛选；类目与保底规则见上文 **play_news_contents** 表说明及「新闻与内容流」小节。
